# Screenshots

Drop screenshot files into this folder using these exact names, then commit —
the main [README](../../README.md#screenshots) renders them automatically.

| File | Screen | What to capture |
|------|--------|-----------------|
| `login.png` | Login | The sign-in screen |
| `dashboard.png` | Dashboard | KPI cards, streak, charts (top fold is enough) |
| `questions.png` | Question manager | Filter bar + problem table |
| `topics.png` | Topic analytics | Topic progress / mastery view |
| `goals.png` | Goals & streaks | Goal progress bars + contribution calendar |

Tips:

- Browser window ~1440×900 gives consistent framing.
- Dark or light theme both fine — match whichever you prefer to showcase.
- No secrets should be visible (avoid shots with emails of real accounts if
  you care; the demo account is fine).
